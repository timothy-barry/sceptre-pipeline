# Local execution scope

Use a fresh native input bundle, environment lock and output directory with the
chosen exact package runtime. Reference and distributed execution call public
package APIs; there is no compact context or compatibility lane.

Keep input counts immutable, use content-addressed staging for native HDF5,
and preserve source/runtime identities with every receipt. A local fixture
comparison establishes only its actual input, runtime and scientific branches.
It does not qualify hosted CI, a scheduler, another architecture or full-screen
scale. Historical work-unit/compact-context owner receipts apply only to their
original artifacts. See [qualification](validation.md).
