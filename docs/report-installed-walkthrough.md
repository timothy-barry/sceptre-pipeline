# Native report boundary

Scientific reports consume public schema-7 package getters after the pipeline
has validated the saved state. Report generation must preserve scientific result
families and original source/runtime provenance. Report failures are separate
from completion of certified scientific computation.

The former schema-3/compact report handoff is retired. Historical screenshots,
mocked contexts and source-only tests do not qualify the native schema-7 runtime.
See [report](report.md), [outputs](outputs.md) and [qualification](validation.md).
